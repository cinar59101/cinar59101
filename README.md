# Hi there, 👋

I'm a self-taught developer focused mainly on **game modding**, **cybersecurity**, low-level system programming, and reverse engineering. I enjoy analyzing how systems work under the hood, building security utilities, desktop tools, and custom hardware.

---

### 🛡️ Core Interests & Focus

* 🎮 **Game Modding & Reverse Engineering:** Analyzing game engines, creating custom mods (C++, Rust, Luau), and dissecting binaries.
* 🔒 **Cybersecurity & Low-Level Dev:** Exploring native Android security utilities, APK analysis, memory manipulation, and Win32 API interactions.
* 💻 **Desktop & Mobile Apps:** Building modern tools with C++, Rust, Qt, Dear ImGui, Tauri, and Jetpack Compose (Kotlin).
* ⚡ **Embedded Systems:** Crafting hardware prototypes and firmware with ESP32, Arduino, and Raspberry Pi Pico.
* 🤖 **AI Experiments:** Training Q-learning reinforcement learning agents in Python.
